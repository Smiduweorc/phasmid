# Phasmid

![Phasmid Logo](https://raw.githubusercontent.com/grMLEqomlkkU5Eeinz4brIrOVCUCkJuN/phasmid/refs/heads/master/assets/logo.png)

Phasmid is an email canonicalization dependency and serves as a counterpart to [emailCanon](https://github.com/grMLEqomlkkU5Eeinz4brIrOVCUCkJuN/emailCanon). It is a re-release of nomad as the scoped release on NPM was causing issues for us.
