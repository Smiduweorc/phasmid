# Phasmid

![Phasmid Logo](https://raw.githubusercontent.com/Smiduweorc/phasmid/refs/heads/master/assets/logo.png)

Phasmid is an email canonicalization dependency and serves as a counterpart to [emailCanon](https://github.com/Smiduweorc/phasmidEqomlkkU5Eeinz4brIrOVCUCkJuN/emailCanon). It is a re-release of nomad as the scoped release on NPM was causing issues for us.
